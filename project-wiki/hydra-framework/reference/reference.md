# Reference

For canonical ownership and maintainer evidence, see the [Source Map](/project-wiki/hydra-framework/reference/source-map.md#maintainer-evidence).

Status: orientation

Reference pages answer lookup questions without becoming a second source of
truth. Start with [Documentation Authoring](/project-wiki/hydra-framework/reference/documentation-authoring.md) when
writing or reviewing pages, [Glossary](/project-wiki/hydra-framework/reference/glossary.md) for terminology, and
[Source Map](/project-wiki/hydra-framework/reference/source-map.md) when a claim needs tracing to its canonical owner.

Use the [Public Positioning Brief](/project-wiki/hydra-framework/reference/public-positioning.md) when changing the
GitHub landing page, preparing evidence assets, or reviewing a public claim.

Use the [Command Surface](/project-wiki/hydra-framework/reference/command-surface.md) for a task-oriented lookup, then
use the [Source Map](/project-wiki/hydra-framework/reference/source-map.md#maintainer-evidence)
to trace exact command behavior.
