# Security Policy

## Supported versions

Hydra is currently a `0.1.x` foundation seed. Security fixes are assessed for
the current default branch. A release-support policy will be added when the
project begins publishing supported releases.

## Reporting a vulnerability

Please do **not** report suspected vulnerabilities in a public issue.

If the repository's Security tab offers **Report a vulnerability**, use that
private reporting form. If it is not available, contact the repository owner
through the contact method listed on their GitHub profile to arrange a
confidential report.

Include a description of the issue, affected files or versions, reproduction
steps or a proof of concept, and the potential impact. Please allow time for a
fix before disclosing details publicly.

## Maintenance

This is a starter policy. Maintainers should enable GitHub private vulnerability
reporting and add a dedicated security contact when one is available.
