
# Knowledge Packages

This directory contains package-local repository knowledge when a repo area has enough durable complexity to justify a repeated local shape.

Do not create a package for every source folder. Create one when the area needs persistent local state, questions, risks, sources, procedures, or testing knowledge.

Use `repo/knowledge/knowledge-packages.md` for the governing concept and placement rules.


## Templates

Reusable package templates live in [`templates/`](templates/README.md). They
encode the default Hydra package workflow: overview reading map, state handoff,
definition of done, problems, context packs, routing metadata, architecture graph,
and package validation wrapper.
